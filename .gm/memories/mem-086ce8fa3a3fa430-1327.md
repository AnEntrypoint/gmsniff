gmsniff/gm comment doctrine (from served entry.md Token Discipline: comments = liability when names+structure encode the same). The transform is NOT blanket deletion, it is three-way: (1) a comment restating what the code does is a defect -- rename the variable, extract the predicate, or name the constant until the code carries the meaning, then delete the prose; (2) a comment recording what code structurally CANNOT encode stays, and only three kinds qualify: a measurement taken against real data, a defect in another repo this code works around, or an alternative tried and rejected; (3) a comment stating a rule that binds future work moves to AGENTS.md rather than living in a source file. Worked examples that set the standard: spoofMarker plus an explaining comment became markerOnLineClaimingAnotherProjectsCwd with no comment; 52 [src,dest] tuples whose halves were always identical (needing a comment to explain the tuple shape) collapsed to a flat list named VENDORED_PATHS_RELATIVE_TO_BOTH_ROOTS; a 26-line usage banner became a real --help string; const same = Buffer.compare(...)===0 became const alreadyByteIdentical. Any comment pass must be proven behavior-preserving by running the real test suite and re-witnessing the affected surface before and after -- a rename missing one call site is a silent break.
